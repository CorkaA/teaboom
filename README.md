# Тестовое задание для Teaboom - карточка товара "Ананасовый улун"

## Описание
Свёрстан вариант блока карточки товара "Ананасовый улун" для магазина чая [Teaboom.ru](https://teaboom.ru/) с использованием материалов с сайта. 

## Что реализовано:

### **Карточка товара**:
- Изображение товара
- Категория, название, краткое описание
- Выбор фасовки (100г, 500г, 1000г, 5000г)
- Артикул, старая и актуальная цена
- Кнопка "В корзину" с hover состояним и мотиватором рядом

### **Нижняя секция**:
- Подробное описание товара
- Состав
- Вкус
- Список полезных свойств

### **Интерактивность**:
- При клике на кнопку веса товара обновляются: артикул, старая цена, новая цена, активное состояние кнопки
- Данных подгружаются асинхронно из JSON файла
- Кнопки веса имеют hover состояние - зелёная обводка и active (светло-зелёная заливка)

### **Адаптивность**:
Блок адаптивен для всех контрольных точек (375px, 768px, 1440px)

### **Технологии**:
- HTML5 - семантическая верстка
- CSS3 - Flexbox, CSS-переменные, медиа-запросы
- JavaScript (ES6) - Fetch API, async/await, работа с DOM
- JSON - хранение данных о товаре (чтобы не засорять файл с разметкой)

### **Структура проекта**:
```text
├── index.html # Основная разметка страницы
├── css/
│ └── style.css # Стили, переменные, медиа-запросы
├── js/
│ ├── data.json # Данные о товаре
│ └── main.js # Логика: загрузка, рендер, обработка кликов
├── images/
│ └── product.jpg # Изображение товара
└── README.md # Этот файл
```

## Как запустить

*Так как в проекте используется fetch(), при открытии index.html браузер заблокирует запрос. Необходим локальный сервер.*

### Вариант Node.js (npx serve) 

1. Проверьте, установлен ли Node.js: `node -v`
2. В терминале проекта выполните:
```bash
   npx serve
```
3. Откройте адрес с терминала (обычно http://localhost:3000)
